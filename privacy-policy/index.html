生效日期：2026-11-23 · 包名：com.linghai.xiongzai · 运营方：山西领嗨者文化传媒有限公司

欢迎使用「领嗨熊仔」。我们重视您的隐私。请在使用前仔细阅读并同意本政策。您点击同意后，我们将按照本政策处理相关信息；广告等第三方 SDK 也可能在您同意后按其规则收集信息。

明示收集字段：本应用及第三方 SDK 可能收集 设备IP地址、Android_ID（亦称 Android ID）、MAC地址（亦称 MAC 地址）等个人信息，用于网络通信、广告投放、反作弊、安全风控与统计分析。具体如下。

1. 我们收集的信息

  • 账号信息：若您注册/登录，可能收集手机号、验证码或第三方登录标识（如微信 OpenID）。
  • 设备信息：设备型号、操作系统版本、网络类型、运营商信息、设备标识符（包括但不限于 Android_ID / Android ID、OAID、IMEI/MEID（在系统与权限允许时）、IMSI、设备序列号、MAC地址 / MAC 地址、SIM 卡序列号、ICCID）、屏幕分辨率、传感器信息（如重力/加速度传感器，用于适配屏幕方向与广告展示）。
  • 网络信息：设备IP地址（含 IP 地址）、网络类型、运营商信息，用于网络通信、安全风控与广告投放。
  • 应用列表信息：已安装应用软件列表 / 软件安装列表（用于广告投放、反作弊与安全风控，主要由广告 SDK 收集）。
  • 存储与文件：在您授权后访问外置存储相关数据，用于缓存、媒体与广告素材读写。
  • 广告标识符：如 Google Advertising ID / 广告 ID，用于广告展示与效果衡量（可在系统设置中限制）。
  • 日志与诊断：设备IP地址、崩溃日志、运行日志、网络诊断信息，用于稳定与安全。
  • 使用数据：浏览、阅读/播放与互动记录，用于内容服务与产品优化。
  • 剪贴板：在特定分享、口令/链接识别场景下可能读取剪贴板内容（如适用）。

说明：上述字段并不表示我们必然全部收集；实际以您的系统版本、授权情况及第三方 SDK 实现为准。若检测到设备序列号等具体字段，本政策按具体名称披露，而非笼统称为「硬件信息」。

2. 使用目的

  • 提供阅读 / 内容浏览等核心功能；
  • 账号管理、客服与安全保障、反作弊；
  • 展示广告、进行广告归因与效果衡量；
  • 遵守法律法规与监管要求。
